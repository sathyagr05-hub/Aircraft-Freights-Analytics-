# ✈️ Aircraft Freight Analysis | Excel & Power BI

## 📌 Project Overview

This mini project focuses on analyzing aircraft freight data to identify freight distribution patterns, top-performing states, and airports based on freight volume.

As an aspiring Data Analyst, I developed this project to gain practical experience in **data cleaning, data transformation, data analysis, and interactive dashboard development** using Microsoft Excel and Power BI.

The project aims to transform raw aircraft freight data into meaningful insights that can support business decision-making.

## 🎯 Project Objectives

- Clean and prepare raw aircraft freight data using Microsoft Excel.
- Handle missing values, duplicate records, and inconsistent formatting.
- Perform data transformation to improve data quality.
- Analyze total freight volume across airports and states.
- Identify the top 5 states based on freight volume.
- Identify the top 5 airports based on freight volume.
- Develop an interactive Power BI dashboard to communicate key insights.

## 📂 Project Workflow

### 1. Data Collection

Collected the raw Aircraft Freight dataset for analysis.

### 2. Data Cleaning & Transformation – Excel

- Removed duplicate records.
- Checked and handled missing values.
- Standardized data formats.
- Organized and structured the dataset.
- Applied conditional formatting.
- Prepared the cleaned dataset for analysis.

### 3. Data Analysis – Power BI

Performed descriptive analysis to answer important business questions:

- What is the total freight volume across all airports?
- Which are the top 5 states by freight volume?
- Which are the top 5 airports by freight volume?
- How is freight distributed across different states?
- Which airports contribute the highest freight volume?

### 4. Dashboard Development – Power BI

Created an interactive dashboard using:

- KPI Cards
- Bar Charts
- Column Charts
- Pie Charts
- Slicers and Filters
- Interactive Visualizations

## 📊 Key Analysis & Insights

The analysis focuses on identifying:

- Total freight volume across airports.
- Top-performing states based on freight volume.
- Top 5 airports contributing to freight transportation.
- Freight distribution patterns across different locations.
- Differences in freight volume among states and airports.
